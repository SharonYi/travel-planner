# Pre-Departure Optimizer — 出发前自动优化器设计

> 行程确定后、出发前的「就绪度引擎」:持续检查准备完备情况,按 T-minus 时间线给出优化建议;外部事件(航变/封闭/改订)触发局部重规划。
>
> 设计目标:**每次输出简洁**——只在「有事要办」或「有险要防」时说话,不说正确的废话。

## 1. 状态文件:`trip-state.md`

每个行程维护一个状态文件(Agent 读写,用户可纠正):

```markdown
# trip-state: <trip-id>(示例为虚构数据)

## 行程概要
- 日期: D1 ~ D12 | 人数: 4 | 出入口: A 城进 → 中转城 → 回国城出

## 预订状态
| 项目 | 日期 | 状态 | 备注 |
|---|---|---|---|
| 国际机票 中国↔A城 | D1 | ✅ 已订 | |
| A 城段包车 3天 | D1–D3 | ✅ 已订 | 机场→Safari→瀑布→火山→机场 |
| A城→B城 机票 | D3 | ⚠️ 尽快订 | 选预留 2h+ 值机窗口的班次 |
| 山脚民宿 | D1 | ✅ 已订 | |
| 码头酒店(旧) | D3 | 🔴 待退 | 渡轮方案作废 |
| 目的国 e-Visa ×4 | 入境D11 | ⚠️ 本周提交 | 官网 .gov 域名,核对入境口岸 |

## 风险监控
| 风险项 | 决策日 | 渠道 | Plan B |
|---|---|---|---|
| 某火山景区关闭 | T-10d ~ T-5d | 当地司机/官方火山监测局 | 邻近国家公园+海滩 / 砍该段改飞行 |
```

## 2. T-minus 检查时间线

出发前倒排,每项给「最晚完成日」:

```
T-30d   国际机票(通常已订,核对时刻)
T-21d   越南 e-Visa 提交(3–5工作日审批+容错)
T-14d   全部酒店锁定 | 快船/船宿预订(旺季)
T-7d    包车连订 | 潜水 DSD 预订 | 火山向导/许可 | 旅行保险(含潜水条款)
T-3d    火山/天气最终确认 | 打印:签证/行程单/预订凭证
T-1d    电子入境卡 | 现金/取款计划 | 装备核对
T-0     出发
```

**触发规则**:每天(或用户唤起时)扫描状态文件,输出仅含:
- 🔴 逾期项(过了最晚完成日还没订)
- 🟠 临界项(3 天内到期)
- 🟡 风险决策日到期提醒

无异常则只回一句「就绪度 X/Y,无逾期项」。

## 3. 事件触发协议

外部事件到达时按以下路由:

| 事件类型 | 响应协议 |
|---|---|
| **航变/改期** | 确认新时刻 → 重排受影响日 → 列退订/新订清单 → 给 2 方案对比 |
| **景点/火山关闭** | 量化风险(频率×影响) → 给 Plan B(算顺路性) → 设决策日,不到决策日不动全局 |
| **酒店变动** | 更新状态文件 → 检查连锁(行李寄存/接驳/次日出发地) |
| **人数变化** | 全局替换人数 → 重算价格/房型/包车座位 |
| **新增目的地意愿** | 先算「塞进现有框架的代价」(在途+退订+连锁),代价>收益时直接说不值 |

## 4. 自动化实现路径

三层递进,按需取用:

**L1 — Skill 手动模式(已可用)**
Claude Code + `SKILL.md` + `trip-state.md`,用户对话驱动,Agent 维护状态文件。

**L2 — 定时任务模式**
Claude Code 的 CronCreate/scheduled task:每天 9:00 扫描 `trip-state.md`,有逾期/临期项才通知(无异常静默)。事件类信息(航变)仍靠用户输入。

**L3 — 事件感知模式**(需外部数据源)
- 航班监控:接入 FlightAware/航司 API(订阅航变 webhook)
- 火山/天气:PVMBG、BMKG 公告页定期抓取
- 就绪度仪表盘:`trip-state.md` 转 JSON,渲染一个静态页(复用 itinerary HTML 模板)

L3 的数据源接入是后续方向;核心协议(状态文件+T-minus+事件路由)三层通用。

## 5. 输出示例(标准格式)

```
📋 出发前检查(T-11d)

🔴 逾期: 无
🟠 临期: 目的国 e-Visa ×4 —— 建议 T-7d 前提交(审批3–5工作日),核对入境口岸与日期
🟡 待退: 码头酒店(D3)、山脚民宿(D2) —— 渡轮方案已作废,尽快退

就绪度 14/17。下次检查:T-8d。
```

> 这就是「简洁」的标准:三行决策信息 + 一行状态。用户 10 秒读完,知道今天要做什么。
